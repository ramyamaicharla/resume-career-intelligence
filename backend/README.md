# Backend - CAREER BUILDING PLATFORM

## Overview
This directory houses the Python/FastAPI backend service powering the CAREER BUILDING PLATFORM.

## Role in Phase 1 (MVP)
- Expose a minimal, career-focused chat endpoint.
- Connect directly to the OpenAI API with a system prompt tailored to career guidance in Data Science, Machine Learning, and GenAI engineering.
- Serve formatted responses back to the Next.js frontend.

## Future Scope
- User state management and session history.
- Relational database storage with PostgreSQL.
- Semantic search & skill gap matching via RAG (`pgvector`).
- Multi-agent workflow orchestration via LangChain & LangGraph.
- System observability, tracing, and evaluation via LangSmith.
